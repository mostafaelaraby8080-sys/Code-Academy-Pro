# CodeAcademy Pro

منصة تعليم برمجة عربية — مبنية بـ HTML و CSS و JavaScript خالص (بدون أي مكتبات أو أطر عمل).

## المميزات

- 7 صفحات: الرئيسية، المسارات، اللغات، المحرر التفاعلي، الاختبارات، التحديات، المصادر
- وضع ليلي/نهاري مع حفظ الاختيار
- حفظ تقدم الدروس بين الجلسات
- محرر كود JavaScript يعمل فعليًا
- تصميم متجاوب بالكامل للموبايل والديسكتوب
- رسائل تنبيه (toast) تفاعلية

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي:

```
npx serve .
```

## البنية

```
index.html        — الهيكل الرئيسي
css/styles.css    — كل التنسيقات
js/app.js         — منطق التطبيق والصفحات
```
